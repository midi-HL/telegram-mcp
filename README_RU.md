# Telegram MCP

[中文](README.md) | [English](README_EN.md) | [日本語](README_JA.md) | [Русский](README_RU.md)

Даёт AI-агентам полный контроль над реальным аккаунтом Telegram через [MCP](https://modelcontextprotocol.io) — отправка сообщений, управление группами и каналами, просмотр профилей, работа с ботами, транскрипция голоса.

Это не Bot API — это **полноценный MTProto-клиент**: чтение личной истории чатов, управление ботами, всё, что Bot API не умеет.

## Возможности

| Возможность | Описание |
|---|---|
| **Чистый Go, без cgo** | Один бинарник для Windows / Linux / macOS / Termux |
| **Экономия токенов** | 12 агрегированных инструментов (8k токенов) вместо 568 мелких (24k+) |
| **Проекция ответов** | `chat list(50)` — 458 токенов (все поля — 133k, экономия 99,7%) |
| **Автораскрытие цитат** | Цитируемые изображения/файлы/голос аннотируются и доступны для скачивания |
| **Уровни доверия** | Сообщения админов без обёртки; внешний контент в `<untrusted_content>` |
| **Web UI** | Доступ по LAN, вход только по паролю, встроен без зависимостей |

## Быстрый старт

### 1. Получите учётные данные Telegram API

Зайдите на https://my.telegram.org → API development tools → создайте приложение. Получите `api_id` и `api_hash`.

### 2. Скачайте

Из [Releases](../../releases) выберите свою платформу:

| Платформа | Файл |
|---|---|
| Windows x64 | `tgmcp-windows-x86_64.zip` |
| Windows ARM64 | `tgmcp-windows-arm64.zip` |
| Linux x64 | `tgmcp-linux-x86_64.tar.gz` |
| Linux ARM64 | `tgmcp-linux-arm64.tar.gz` |
| Linux ARMv6/v7 | `tgmcp-linux-armv6.tar.gz` / `armv7` |
| Linux RISC-V 64 | `tgmcp-linux-riscv64.tar.gz` |
| Linux LoongArch 64 | `tgmcp-linux-loong64.tar.gz` |

Есть пакеты `.deb` (Debian/Ubuntu) и `.rpm` (RHEL/Fedora).

### 3. Вход

```bash
# QR-сканирование (рекомендуется)
./tgmcp auth --account main --qr

# Или по номеру телефона
./tgmcp auth --account main --phone +79001234567
```

### 4. Настройте MCP-клиент

**Claude Code** (`~/.claude.json` или `.mcp.json` в проекте):

```json
{
  "mcpServers": {
    "telegram": {
      "command": "/path/to/tgmcp",
      "args": ["serve"],
      "env": {
        "TGMCP_DATA_DIR": "/path/to/data"
      }
    }
  }
}
```

**Cursor** (`~/.cursor/mcp.json`): тот же формат.

**VS Code** (`.vscode/mcp.json`):

```json
{
  "servers": {
    "telegram": {
      "type": "stdio",
      "command": "/path/to/tgmcp",
      "args": ["serve"]
    }
  }
}
```

### 5. Использование

Просто говорите с AI:

- «Покажи все мои группы с непрочитанными»
- «Прочитай последние 20 сообщений в группе X»
- «Перешли это сообщение в другую группу»
- «Отправь @someone сообщение "привет"»
- «Покажи профиль @Eddie»
- «Используй @some_bot, чтобы получить сегодняшний чек-ин»

## Web UI

После запуска откройте `http://<ваш-ip>:8080/ui`.

| Страница | Функция |
|---|---|
| Аккаунты | Статус аккаунтов, статистика кэша |
| Чаты | Список чатов + сообщения + ручная отправка |
| Автоответ | Настройка правил + переключатель + логи |
| Голос | Настройка ASR-бэкенда и путей |
| Админы | Добавление/удаление админов (хранится числовой ID) |
| Настройки | Смена пароля, информация о сервисе |

**Пароль по умолчанию `Admin`** — смените его сразу после первого входа.

## Команды

```bash
tgmcp auth      Вход (--qr сканирование / --phone)
tgmcp serve     Запуск MCP-сервиса (--http для HTTP-транспорта)
tgmcp doctor    Проверка окружения
tgmcp asr       Настройка транскрипции (setup / status / config)
tgmcp version   Версия
```

## 12 инструментов

| Инструмент | Возможности |
|---|---|
| `system` | Статус сервиса, список аккаунтов, проверка окружения |
| `chat` | Список чатов, детали, непрочитанные, отметка о прочтении, папки |
| `message` | Отправка/редактирование/удаление/пересылка/поиск/история/реакции/закрепление + **раскрытие цитат** |
| `group` | Участники, приглашение/кик, админы, права, одобрение, вход/выход, комментарии |
| `contact` | Страница профиля, контакты, поиск, добавление, блокировка |
| `media` | Отправка фото/файлов/видео/голоса/альбомов, скачивание, **просмотр изображений по запросу** |
| `sticker` | Наборы стикеров, отправка стикеров, кастомные эмодзи, реакции |
| `account` | Свой профиль, смена имени/био/аватара/username, сессии |
| `bot` | Управление своими ботами, inline-запросы |
| `botuse` | Использование чужих ботов (чтение кнопок, клик по колбэкам, WebApp) |
| `asr` | Голос в текст (4 бэкенда) |
| `stats` | Статистика групп, чатов, кэша |

## Настройка путей ASR

Если sherpa-onnx уже установлен, укажите существующие пути:

```bash
# Переменные окружения (высший приоритет)
export TGMCP_ASR_MODEL_DIR=/opt/sherpa/models/paraformer-zh-small
export TGMCP_ASR_CLI=/usr/local/bin/sherpa-onnx-offline

# Или через конфиг
tgmcp asr config --cli /usr/local/bin/sherpa-onnx --model-dir /opt/sherpa/models/...

# Или постоянная настройка
tgmcp asr setup   # пропускает скачивание, если модель уже есть
tgmcp asr status  # показывает разрешённые пути
```

**Приоритет**: переменные окружения > `config.json` > по умолчанию `{DataDir}/models/...`

Распознаваемые файлы модели: `model.onnx`, `model.int8.onnx`, `encoder.onnx`, `encoder.int8.onnx`, `paraformer.onnx`.

## Конфигурация

Каталог данных по умолчанию `~/.tgmcp`, переопределяется `TGMCP_DATA_DIR`.

```
~/.tgmcp/
├── config.json          # Конфиг
├── cache.db             # SQLite-кэш (чаты/сообщения/пользователи/админы)
├── sessions/
│   └── main/
│       └── session.json # Сессия Telegram (★ содержит auth key, храните в тайне)
├── models/              # Модели ASR
└── downloads/           # Скачанные медиа
```

## Безопасность

- **Файл сессии — открытый JSON** (содержит auth key). Утечка = компрометация аккаунта.
- **Админы идентифицируются по числовому UserID** — username можно изменить/занять, поэтому не используйте его как первичный ключ.
- **Пароль Web UI по умолчанию `Admin`** привязывается к `0.0.0.0`, то есть доступен любому в LAN. Смените пароль немедленно.
- **Сообщения админов обходят защиту от инъекций** — если аккаунт админа скомпрометирован, модель тоже.
